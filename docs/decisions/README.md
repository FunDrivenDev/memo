# Decisions

Why memo is the way it is, one decision per file, numbered in the order they were made. A decision that changes gets a new file that replaces the old one, which says so at its top.

- [0001](0001-one-key-one-action.md): one key, one action
- [0002](0002-comments-beside-the-note.md): comments live beside the note, never in it
- [0003](0003-no-column-of-keys.md): no column of keys beside the note
- [0004](0004-remembered-session-folders.md): session folders are remembered, the usual ones first
