# No column of keys beside the note

A thin column beside the note once listed the keys that acted on it, changing with what was going on (`c` over a selection, `r` on a focused comment). It was removed: it did not work in practice.

It took width from the note, hid itself in windows narrower than 1000 pixels, and a list that changes with the context is hard to learn from. With [one key per action](0001-one-key-one-action.md) there is less to recall, and `?` (every key) and `⌘K` (every command, with its key) cover discovery.
